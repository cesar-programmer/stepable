## Plantilla para próximas decisiones

ID y título; fecha; estado (propuesto/aceptado/sustituido); contexto; alternativas; decisión; consecuencias; documentos afectados; fundamento de aceptación; ADR que sustituye, si aplica.

No modificar una decisión antigua para ocultar un cambio. Conservarla, marcarla sustituida y enlazar la nueva.

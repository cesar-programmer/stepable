# ADR-001 · Enfoque del producto y base V0

Fecha: 2026-09-17 · Estado: aceptado como base de planificación.

## Contexto

Los cuatro PDF mezclan visión comercial, requisitos y opciones técnicas. El usuario aclaró que desarrollará Stepable solo con Codex, para validar una idea propia y usarla como portafolio.

## Decisión

Mantener onboarding interactivo y consulta permanente como usos centrales. Empezar por software, preservando una visión futura más amplia. Usar [02-alcance-v0](../02-alcance-v0.md) como base del primer recorrido completo.

## Alternativas consideradas en conversación

- Priorizar exclusivamente chat o exclusivamente onboarding: el usuario indicó que necesita ambos.
- Lanzar desde el principio para todas las áreas: el usuario eligió inclinar el inicio a software por su experiencia.
- Plugin o conector como centro inicial: el alcance presentado usa una plataforma web y carga manual; esas integraciones quedan fuera de V0.

## Consecuencias

La V0 debe demostrar ambos usos juntos. No se ejecutará código ni se conectará Atlassian automáticamente en esta base. Detalles técnicos y de reglas quedan abiertos en [08-pendientes](../08-pendientes.md).

## Fundamento

Decisiones expresadas en esta conversación y aceptación del usuario para avanzar con la V0 presentada. No constituye aprobación de frameworks, proveedores, gastos o despliegue.

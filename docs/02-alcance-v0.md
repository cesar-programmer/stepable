# Alcance de la V0

Estado: base aceptada para planificación; detalles pendientes en documento 08.
Actualizado: 2026-09-17.

## Resultado completo

Responsable carga fuentes → genera y revisa ruta → publica → integrante aprende y conserva progreso → consulta al asistente durante y después del recorrido.

## Incluido

| ID | Capacidad |
| --- | --- |
| RF-01 | Cuentas, inicio de sesión, recuperación e invitaciones; mecanismo técnico pendiente |
| RF-02 | Espacio por proyecto y roles responsable/integrante |
| RF-03 | Carga de PDF con texto y Markdown; estados y reintentos de procesamiento |
| RF-04 | Generación de borrador de ruta con objetivo y fuentes seleccionadas |
| RF-05 | Edición, reordenamiento, eliminación de pasos y publicación supervisada |
| RF-06 | Lecciones breves, opción múltiple, lectura de código y completar fragmentos acotados |
| RF-07 | Retroalimentación, reintentos y progreso persistente por versión de ruta |
| RF-08 | Chat general y ayuda contextual en lecciones con fuentes verificables |
| RF-09 | Vista de avance y resultados para responsable |
| RF-10 | Manejo de errores, control de consumo de IA y límites por definir |

No todas las rutas requieren código. El responsable selecciona las actividades pertinentes. La personalización inicial se basa en contenido y configuración de cada equipo; no se promete adaptación automática de toda la ruta.

## Fuera de V0

- Conectores automáticos de Confluence, GitHub u otros: carga manual inicialmente.
- Plugin de editor, navegador o chat empresarial.
- Ejecución de código, sandbox o evaluación de programas libres.
- Rutas ramificadas, adaptación automática por desempeño, ligas o recompensas avanzadas.
- Cobros, planes comerciales y SSO corporativo.
- OCR, documentos escaneados e ingesta de URLs arbitrarias.
- Lanzamiento especializado para otras áreas empresariales.
- Ejercicio de ordenar pasos: idea explorada antes, no incluido en esta base V0.

## Tratamiento del alcance

Integraciones futuras no implican construir desde ahora un framework de plugins. Los detalles de límites, eliminación, permisos y calificación se deben resolver antes de implementar los comportamientos afectados. No hay plazos o precios aceptados.

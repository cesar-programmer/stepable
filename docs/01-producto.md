# Producto y visión

Estado: dirección acordada · Actualizado: 2026-09-17.

## Definición

Stepable transforma el conocimiento interno de una empresa en experiencias interactivas de onboarding y ofrece un asistente permanente para consultar cómo realizar el trabajo según sus procedimientos. La primera versión se enfoca en equipos de desarrollo de software.

## Problema observado

El usuario conoce por experiencia equipos con procedimientos específicos para contratos de API y uso de assets de íconos. Las instrucciones estaban en documentación de Atlassian. El producto concreto de Atlassian no se confirmó: Confluence es una posibilidad, no un hecho establecido.

Conocer una tecnología no garantiza conocer las convenciones del equipo. La hipótesis es que rutas prácticas y consultas con fuentes faciliten aprender y aplicar esas convenciones. No existe aún validación externa de utilidad o disposición a pagar.

## Usuarios y objetivos

- Integrante: aprender procedimientos del proyecto y resolver dudas durante su trabajo.
- Responsable: seleccionar fuentes, revisar rutas y seguir el avance.
- Comprador hipotético: responsable de ingeniería o empresa; pendiente de validar.
- Creador: una persona con apoyo de Codex; busca validar un producto y mostrarlo en su portafolio.

Hay conocidos que podrían probarlo, pero no un piloto confirmado ni fecha comprometida. El presupuesto indicado para primeras pruebas es de unos 10 USD mensuales; ver PEN-01 en [pendientes](08-pendientes.md).

## Dos usos centrales

1. Onboarding: pasos cortos, lecciones, actividades y retroalimentación.
2. Consulta continua: ayuda sobre cómo se trabaja en la empresa, durante y después de completar una ruta.

Ambos usan fuentes del mismo proyecto. La visión abarca otras áreas empresariales; el lanzamiento se limita según [el alcance](02-alcance-v0.md).

## Vocabulario

| Término | Significado |
| --- | --- |
| Espacio | Contexto de un proyecto, sus miembros y conocimiento |
| Fuente | Documento autorizado para aportar información |
| Versión de fuente | Contenido concreto de una fuente en un momento |
| Ruta | Secuencia de pasos para un objetivo de aprendizaje |
| Actividad | Paso con una tarea y criterios de evaluación |
| Cita | Referencia comprobable a un fragmento de una versión de fuente |
| RAG | Recuperar información de fuentes para fundamentar generación; no entrenar el modelo |

Completar una ruta demuestra progreso interno, no que se haya realizado una contribución real ni que se haya reducido el tiempo de onboarding. Eso requiere evidencia adicional.
